# The System (Solo Leveling-inspired daily quests)

Easiest way to get the APK (no installs):
1. Create a free GitHub repo and upload everything in this folder (keep the .github folder).
2. Open the Actions tab, wait about 3 minutes for "Build APK" to finish.
3. Download SoloSystem-APK, unzip it, install app-debug.apk on your phone.

Or with Android Studio: File > Open this folder > Build > Build APK(s).

The app itself lives in app/src/main/assets/index.html.
